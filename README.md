# 도담도담

가족이 매일 같은 질문을 받고 서로의 답을 보는 안드로이드 앱입니다. 2023년에 팀 프로젝트로 만들었습니다.

## 기능

- 가족 코드로 가족 연결, 구성원 관리
- 오늘의 질문에 답하고 가족의 답 보기
- 채팅방. 질문을 보내면 GPT가 답하는 대화도 들어 있습니다.
- 시와 소설 읽기
- 알림, 이름과 전화번호 수정

## 기술

Kotlin, XML 레이아웃, Retrofit, OkHttp, Room, Navigation, Firebase Realtime Database

## 실행

Android Studio로 열어서 실행합니다. minSdk 24입니다.
